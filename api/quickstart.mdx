## Get Your API Key

1. Go to [alpha.ac/settings/api](https://alpha.ac/settings/api)
2. Click **Generate API Key**
3. Copy the key (it will only be shown once)
4. Store it securely. Never expose it in client-side code.

<Warning>
API keys are hashed with SHA-256 before storage. Alpha cannot retrieve your key if lost. Generate a new one if needed.
</Warning>

## Make Your First Request

<CodeGroup>

```bash cURL
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.alpha.ac/functions/v1/api-gateway/v1/ratings/AAPL
```

```python Python
import requests

headers = {"Authorization": "Bearer YOUR_API_KEY"}
response = requests.get(
    "https://api.alpha.ac/functions/v1/api-gateway/v1/ratings/AAPL",
    headers=headers,
)
data = response.json()

print(f"Grade: {data['rating']['grade']}")
print(f"Tier: {data['rating']['tier']}")
print(f"Trajectory: {data['rating']['trajectory']}")
```

```typescript TypeScript
const response = await fetch(
  "https://api.alpha.ac/functions/v1/api-gateway/v1/ratings/AAPL",
  {
    headers: { Authorization: "Bearer YOUR_API_KEY" },
  }
);
const data = await response.json();

console.log(`Grade: ${data.rating.grade}`);
console.log(`Tier: ${data.rating.tier}`);
```

</CodeGroup>
