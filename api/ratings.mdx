## Get Rating by Ticker

<ParamField path="ticker" type="string" required>
  Stock ticker symbol (e.g., AAPL, MSFT, GOOGL)
</ParamField>

```
GET /v1/ratings/{ticker}
```

Returns the current Alpha Governance Rating for the specified company, including dimension scores, trajectory, and methodology metadata.

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `ticker` | string | Stock ticker |
| `company_name` | string | Full company name |
| `exchange` | string | Stock exchange (NYSE, NASDAQ, etc.) |
| `sector` | string | Industry sector |
| `rating.grade` | string | Letter grade: AAA through D, or NR |
| `rating.tier` | string | Leaders, Governance-Ready, Developing, Laggards, Disqualified |
| `rating.score` | number | Composite score 0-100 (enterprise/institutional only) |
| `rating.trajectory` | string | Advancing, Stable, or Declining |
| `rating.watch` | string | positive_watch, negative_watch, or null |
| `rating.confidence` | string | high, medium, or low |
| `rating.rating_type` | string | "public" (independent) or "assessed" (engaged) |
| `rating.is_assessed` | boolean | Whether company has a full Assessed Rating |
| `dimensions` | array | D1-D12 dimension scores (enterprise/institutional only) |
| `methodology_version` | string | Current methodology version |
| `rated_at` | string | ISO 8601 date of last rating |

### Dimension Scores

Each dimension object:

```json
{
  "number": 2,
  "name": "AI Safety & Robustness",
  "score": 6.8,
  "weight": 0.123,
  "confidence": "medium"
}
```

<Note>
Dimension scores are only available on Enterprise and Institutional tiers. Research and Professional tiers receive the top-level grade and tier only.
</Note>

### Alpha Governance Scale

| Grade | Tier | Score Range |
|-------|------|-------------|
| AAA | Leaders | 90-100 |
| AA | Leaders | 85-89 |
| A | Leaders | 80-84 |
| BBB | Governance-Ready | 70-79 |
| BB | Governance-Ready | 60-69 |
| B | Developing | 50-59 |
| CCC | Developing | 40-49 |
| CC | Laggards | 30-39 |
| C | Laggards | 20-29 |
| D | Disqualified | 0-19 |
| NR | Not Rated | n/a |

## Get Rating History

```
GET /v1/ratings/{ticker}/history
```

Returns all historical ratings for a company, ordered by date descending.

<ParamField query="limit" type="number" default="10">
  Maximum number of historical ratings to return
</ParamField>

<ParamField query="since" type="string">
  ISO 8601 date. Only return ratings after this date.
</ParamField>

### Response

```json
{
  "ticker": "MSFT",
  "company_name": "Microsoft Corporation",
  "history": [
    {
      "grade": "A",
      "score": 82.1,
      "trajectory": "Advancing",
      "rated_at": "2026-04-01T00:00:00Z",
      "methodology_version": "2.0"
    },
    {
      "grade": "BBB",
      "score": 76.3,
      "trajectory": "Stable",
      "rated_at": "2026-01-15T00:00:00Z",
      "methodology_version": "2.0"
    }
  ],
  "total_ratings": 4
}
```

## Batch Ratings

```
POST /v1/ratings/batch
```

Query multiple companies in a single request. Maximum batch size depends on your tier.

### Request Body

```json
{
  "tickers": ["AAPL", "MSFT", "GOOGL", "META", "AMZN"],
  "include_dimensions": true
}
```

### Response

```json
{
  "ratings": [
    { "ticker": "AAPL", "grade": "BBB", "tier": "Governance-Ready", "score": 72.4 },
    { "ticker": "MSFT", "grade": "A", "tier": "Leaders", "score": 82.1 },
    { "ticker": "GOOGL", "grade": "BB", "tier": "Governance-Ready", "score": 65.7 }
  ],
  "not_found": [],
  "total": 5,
  "methodology_version": "2.0"
}
```

## Embeddable Rating Badge

No API key required. Embed a governance rating badge on any webpage.

```html
<img src="https://api.alpha.ac/functions/v1/rating-badge/AAPL" alt="Alpha Governance Rating" />
```

### Parameters

| Parameter | Values | Default | Description |
|-----------|--------|---------|-------------|
| `style` | `full`, `compact` | `full` | Badge layout |
| `theme` | `dark`, `light` | `dark` | Color theme |

### Examples

Full badge:
```
https://api.alpha.ac/functions/v1/rating-badge/AAPL
```

Compact badge:
```
https://api.alpha.ac/functions/v1/rating-badge/AAPL?style=compact
```

Badges are cached for 24 hours via CDN and update automatically when ratings change.

## Error Responses

| Status | Error | Description |
|--------|-------|-------------|
| 401 | `unauthorized` | Invalid or missing API key |
| 403 | `insufficient_tier` | Your tier does not have access to this data |
| 404 | `company_not_found` | Ticker not in Alpha's coverage universe |
| 429 | `rate_limit_exceeded` | Daily call limit reached |
| 500 | `internal_error` | Server error (contact support) |

```json
{
  "error": "rate_limit_exceeded",
  "message": "Research tier limit: 1000 calls/day. Upgrade at alpha.ac/settings/api",
  "calls_today": 1001,
  "limit": 1000
}
```
