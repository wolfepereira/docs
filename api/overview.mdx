The Alpha Data API provides programmatic access to governance intelligence for integration into your compliance workflows, risk platforms, and investment processes.

## Base URL

```
https://api.alpha.ac/functions/v1/api-gateway/v1
```

## Authentication

All requests require an API key in the Authorization header:

```
Authorization: Bearer YOUR_API_KEY
```

Generate your key at [alpha.ac/settings/api](https://alpha.ac/settings/api).

## Response Format

All responses return JSON with consistent structure:

```json
{
  "ticker": "AAPL",
  "company_name": "Apple Inc.",
  "rating": { ... },
  "methodology_version": "2.0",
  "methodology_url": "https://alpha.ac/institute/methodology",
  "limitations_disclosure": "Alpha Governance Ratings are based on publicly available evidence and proprietary signal analysis. They represent Alpha's independent assessment and are not guarantees of future governance performance."
}
```

Every rating response includes `methodology_url` and `limitations_disclosure` for regulatory compliance.

## Rate Limiting

Rate limits are enforced per API key per day. When exceeded:

```json
{
  "error": "rate_limit_exceeded",
  "calls_today": 1001,
  "limit": 1000,
  "resets_at": "2026-04-05T00:00:00Z"
}
```

## Caching

Responses include standard caching headers:

```
Cache-Control: public, max-age=3600
ETag: "abc123"
```

Rating data is refreshed on a rolling basis. Use `If-None-Match` headers to reduce bandwidth.
